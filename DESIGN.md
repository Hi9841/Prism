# Prism design

## Visual character

The landing page uses a bright Windows workspace so Prism's near-black application window remains the unmistakable product object. Black editorial type, thin system-like rules, and a restrained violet signal create contrast without competing with the interface. Product imagery must be a current screenshot or a frame taken from the real application demo. Do not use rendered substitutes.

## Color

- Canvas: `#f1f2f5`
- Paper: `#fbfbfc`
- Primary text: `#111217`
- Secondary text: `#62646e`
- Accent: `#745ce8`
- Accent strong: `#5741bf`
- Dark band: `#0b0c11`
- Hairline: `#d7d8de`

Violet identifies Prism and carries the final action. Amber is reserved for the installer warning. Dark sections are evidence stages for real product media, not the default page canvas.

## Typography

Use Segoe UI Variable and Segoe UI to stay native to Windows. Display text is direct, heavy, sentence case, and uses zero letter spacing. Body text stays between 16px and 18px with a readable measure. Monospace is limited to paths, shortcuts, versions, and calculations.

## Shape and depth

Marketing sections remain unframed. Real application captures retain their native rounded window shape and may use one restrained shadow. Buttons use 4px corners. Small media controls may be circular when the familiar play or pause symbol makes their purpose clear. Avoid cards as section containers and never nest cards.

## Layout

The first viewport pairs a three-beat command headline, Find, Open, Control, with the current Prism launcher. Wide screens use an asymmetric two-column composition with the command sequence on the left and the real product on the right. Full-width evidence bands alternate light and dark, with captures kept large enough to inspect. Narrow screens preserve the command sequence and primary action, then reveal the launcher within the first viewport.

## Motion

The hero runs one short explanatory entrance on first load. The three command words arrive in 60ms steps while the real launcher settles beside them. The actual Prism keyboard launcher remains instant. The demo video starts only when requested. Hover and press feedback stays under 180ms, and reduced motion replaces position changes with a 200ms fade. Core content remains visible without JavaScript.

## Voice

Use short, factual sentences. Name the Windows action and its result. Do not fabricate performance numbers, testimonials, customer claims, or security promises. State platform and installer limitations plainly.
