Agreed Architecture & Contracts

  • Support Floor: Permissive 640×480 logical DIP work area.
  • Unit Contract: Logical DIP everywhere; physical conversion strictly at Win32 boundaries.
  • Mixed-DPI Multi-Monitor: Preserve logical dimensions by scaling physical pixels per monitor.
  • Height Clamping: Clamp window height to work area; search input pinned, results list scrollable.
  • Zoom Semantics: Content-only webview zoom; native window geometry decoupled and preset-governed.
  • Container Breakpoints: Width < 700px collapses secondary hints; height < 520px compacts padding/badges.
  • Native Safety Floor: Retain 480×400 in tauri.conf.json as OS safety net.
  • DPI Synchronization: Recalculate on summon/show and listen for ScaleFactorChanged / WM_DPICHANGED.
  • Width Transitions: Instant 0ms native window resize via set_window_width (zero Win32 stutter).
  • Scroll Containment: Pinned header/footer; results container has overflow-y: auto and scrollbar-gutter: stable.
