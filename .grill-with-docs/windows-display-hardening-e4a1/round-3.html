Round 3 · Final synthesis and authorization

Agreed Architectural Decisions

  • Baseline Support: 640×480 logical work area floor with graceful compact degradation.
  • Unit Contract: Logical DIP everywhere across IPC, settings, and state; converted to physical pixels strictly at Win32/Tauri boundaries.
  • Mixed-DPI Movement: Preserve logical dimensions across monitors by recalculating physical pixels (logical * target_dpi).
  • Height Clamping: Native window height clamps to monitor work area; search bar stays pinned, results list scrolls smoothly.
  • Zoom Semantics: Content-only webview zoom; native window frame size remains decoupled and governed by presets.
  • Container Breakpoints: Multi-stage container queries (width < 700px collapses secondary action hints; height < 520px collapses badges/tightens padding).
  • Native Safety Floor: Retain 480×400 in tauri.conf.json as OS safety net while UI targets 640×480.
  • DPI Synchronization: Recalculate on summon/show and listen for ScaleFactorChanged / WM_DPICHANGED events.
  • Width Transitions: Instant 0ms native resize via set_window_width; internal CSS transitions smoothly.
  • Scroll Containment: Pinned search header/footer; results container has overflow-y: auto and scrollbar-gutter: stable.
