Window audit resolved

Every actionable item from the original window-material audit is resolved in Prism 0.9.32. The old Acrylic and Mica implementation no longer exists, and the remaining theme, error-reporting, test, and elevated Win-key issues are fixed.

Primary corner bug

Resolved by removing native backdrop materials. Prism now enforces a solid-only native surface with set_effects(None). Acrylic, Mica, Blur, the fallback ladder, and the ineffective Windows radius setting have been removed. With no DWM backdrop painting behind the transparent webview, the CSS shell is again the only visible corner shape.

Adding DWMWA_WINDOW_CORNER_PREFERENCE is no longer appropriate. That recommendation applied to the old material system and would introduce a second native radius that does not match Prism's current shell silhouette.

Finding-by-finding resolution

  1. Resolved

    1. Silent material downgrade

    The material selector and fallback ladder were removed. There is now one authoritative surface: solid. The UI cannot display a material that differs from the native window.

  2. Resolved

    2. Style IPC errors were swallowed

    set_window_style now propagates both native theme and surface errors. The frontend shows a persistent, dismissible error toast instead of discarding the rejection. Error toasts use an alert icon rather than a success checkmark.

  3. Resolved

    3. Startup theme was hardcoded

    Native setup now resolves the persisted light, dark, or system preference before the first frontend render. Runtime changes use the same apply_window_style contract.

  4. Resolved

    4. Dead material radius configuration

    The old EffectsBuilder.radius(12.0) call no longer exists. The current native path contains no effect builder or ignored radius value.

  5. Resolved

    5. Clippy warnings

    The reported nested conditionals are gone. Clippy passes across every Rust target with warnings treated as errors.

  6. Resolved

    6. Defensive material copy

    The material setting and its "Solid avoids DWM blur issues" copy were removed with the unsupported material choices.

  7. Resolved

    7. Missing style regression coverage

    Pure tests now cover persisted and system startup-theme resolution plus strict runtime theme parsing. Material ladder tests are obsolete because no ladder remains.

Elevated test-app issue

Resolved: Explorer can acknowledge an elevated Prism process. The screenshot failure occurred because Explorer runs at medium integrity while the test app inherited a high-integrity shell. Windows blocked Explorer's bridge acknowledgment. Prism now allows only its private registered bridge message through the observer window's message filter. The elevated reproduction reaches bridge-install-ok.
